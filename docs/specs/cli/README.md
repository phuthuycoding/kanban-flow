# cli capabilities

## Capabilities
- [config-layers](config-layers.md) — global and workspace config layers for `reviewer`, `agents` and `skills`, and `kf config show/get/set`
- [install](install.md) — `kf install` / `kf uninstall`: skills and agents at global, project or workspace scope, the Claude Code plugin, and the step-by-step terminal onboarding
- [item-lifecycle-log](item-lifecycle-log.md) — the append-only `lifecycle.jsonl` of every work item, the item `id`, and the `kf doctor` check and repair
- [item-metrics](item-metrics.md) — the contract estimate `kf approve` records, the files changed counted on entering review, the item's `metrics.json` written at the close, and `kf estimate` / `kf metrics`: estimation and measurement as harness data that travel only reads
- [library-entry](library-entry.md) — the `@phuthuycoding/kanban-flow/lib` import path: kf's ledger, item and lifecycle-log readers for another program, without git or host config, with type declarations and stable/experimental marks
